# Documentation plans

Implementation specs are split by **phase**:

| Track | Folder | Status |
|-------|--------|--------|
| **Phase 1 — PoC** | [poc/](poc/README.md) | Frozen — all specs in [poc/archive/](poc/archive/) |
| **Phase 2+ — Product** | [product/](product/README.md) | Active — new specs live here |

**Roadmaps:** PoC phase summary [poc/PROJECT_SUMMARY.md](poc/PROJECT_SUMMARY.md) · Product [PRODUCT_ROADMAP.md](../../PRODUCT_ROADMAP.md)

**ADRs:** [decisions/poc/](../decisions/poc/) (0001–0004) · [decisions/product/](../decisions/product/) (0100+).

Do not leave the only copy of a plan under `.cursor/plans/` — promote into `docs/plans/poc/` or `docs/plans/product/` and link from the matching roadmap.
